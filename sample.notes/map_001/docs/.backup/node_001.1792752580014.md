# 统一虚拟化块编辑器

这是一个用于验证 **BlockIndex + 虚拟列表** 的演示文档。它包含标题、段落、列表、引用、代码、表格和分割线。

## 为什么用块级虚拟化？

- 一个编辑器覆盖所有文档大小
- 不切换“大文档模式”
- 代码块内部可以单独使用 CodeMirror
- 文档结构仍·然是 Markdown


> 统一体验的关键不是“换一个编辑器”，而是“换一种挂载方式”。

```rust
fn main() {
    println!("hello, block editor");
}
```
