# 移动端真机检查清单

> 最后核对：2026-11-02  
> 当前状态：Android 工程已初始化；Android 15 模拟器已验证启动、新建、导入、导出、分享和 390 宽度。  
> 适用版本：v0.1.1

## 1. 视口与安全区

- [x] 390 × 844：无横向滚动，导图/目录/文档可切换（模拟器）。
- [ ] 600 × 800：移动 Shell 保持，tabbar 四项可见。
- [ ] 768 × 1024：进入 tablet/dock Shell，不出现移动 tabbar。
- [ ] 刘海/圆角设备：header 不被 system bar 遮挡。
- [ ] 横屏：内容不被裁切，键盘弹出后仍可滚动到输入点。

## 2. 触摸与手势

- [ ] 长按文档行打开动作面板。
- [ ] 左滑文档行打开动作面板。
- [ ] 右滑边缘返回。
- [ ] 动画期间快速重复滑动不会打开多个面板。
- [ ] 滚动列表时不会误触长按。

## 3. 键盘与编辑

- [ ] 点击文档进入只读视图。
- [ ] “编辑”进入编辑器后键盘自动聚焦。
- [ ] 键盘弹出时当前光标行保持可见。
- [ ] “保存”后提示保存成功。
- [ ] “完成”退出编辑态。
- [ ] 切后台/锁屏再回来，编辑内容不丢。

## 4. 书库

- [x] 空状态可打开/新建知识库（模拟器）。
- [x] 新建时输入标题，生成 App 私有书库（模拟器）。
- [x] 从外部 `.note` 导入后，书库列表出现新条目（模拟器）。
- [ ] 切换书库后导图/目录刷新。
- [ ] 导出到保存位置后文件可重新打开。
- [x] 当前书库有“当前”标记（模拟器）。

## 5. 系统行为

- [ ] 按 Home / 切后台触发保存。
- [ ] 杀进程后重新打开，最后工作区仍可恢复。
- [ ] 低存储空间时给出可读错误。
- [ ] 无网络时不影响本地书库（远程同步尚未实现）。
