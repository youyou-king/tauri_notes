# 布局架构契约

> 最后核对：2026-10-31 | 当前版本 v0.1.1 | 基线 133 / 38 / 33

> 状态：2026-10-28  
> 适用范围：Tauri Notes 全部界面、Dockview 面板、Tiptap 全块编辑器、内容 Widget。  
> 面板/Grid/滚动契约继续有效；文档编辑层已经按 [全块编辑器架构](全块编辑器架构.md)
> 使用 ProseMirror 块编辑器和 12 列布局。

## 1. 分层

```text
AppShell（Grid：顶栏 + 工作区）
└─ Workspace（Grid：状态区 + Dock）
   └─ Dock Panel（dockview）
      └─ BlockDocumentPane
         ├─ 文档标题 / 状态栏
         └─ EditorSurface
            └─ imported-preview-surface（唯一滚动者）
               └─ Tiptap/ProseMirror 块编辑器
                  └─ 内容 Widget（表格/代码/导图视口）
```

每层只决定自己的尺寸，不修改父级或第三方组件的几何。

## 2. 核心规则

1. 所有可收缩的 Grid/Flex 子项必须有 `min-width: 0`、`min-height: 0`。
2. 每个 Pane 只能有一个滚动所有者：
   - Dockview 不滚；
   - 文档外壳不滚；
   - 编辑内容由 `.imported-preview-surface` 滚动；
   - 表格/代码块/视口可以在内部拥有自己的横向或纵向滚动。
3. 内容最大宽度、左右留白只在一个地方定义：
   - `--content-max-width`
   - `--content-gutter`
4. 不在 ProseMirror 块节点上使用会改变测量坐标的外层 margin；块间距由内部 padding 和布局规则控制。
5. 内容 Widget 不得改变父级宽度：
   - 表格使用固定布局和内部滚动；
   - 表格/代码块操作按钮只做内部浮层；
   - 视口内容不撑破所在列。
6. 动态高度由 Tiptap/ProseMirror 的文档测量和块高度规则管理，不能靠外层固定高度模拟。
7. 第三方组件只通过公开主题/扩展点定制，不用普通 CSS 改内部几何。

## 3. CSS 约束

```css
.app {
  display: grid;
  grid-template-rows: var(--pane-header-height) minmax(0, 1fr);
}

.workspace {
  display: grid;
  grid-template-rows: auto minmax(0, 1fr);
}

.imported-preview-pane {
  display: grid;
  grid-template-rows: auto minmax(0, 1fr);
  min-height: 0;
}

.imported-preview-surface {
  min-height: 0;
  overflow: auto;
}
```

禁止：

- 让 `.dv-dockview` 或 `.dv-content-container` 承担文档滚动；
- 用外层 `padding` 给编辑器内容留白，导致点击坐标偏移；
- 给表格外层加预留 padding 来放操作按钮；
- 用 `height: 100%` 猜测一个没有 `min-height: 0` 的父级；
- 用固定高度模拟动态块高度。

## 4. Dockview 默认布局

```text
outline（左，240）
document（中，剩余）
map + console（右，320）
```

- 首个文档插入导图左侧，不与导图合并 Tab；
- 所有面板创建完成后再设置默认宽度；
- 保存布局的 key 变更时，丢弃旧的不兼容布局；
- 窄窗口隐藏后端状态，工具栏不换行。

## 5. Widget 规则

### 表格

- 宽度不超过所在块/列；
- 固定表格布局，长内容在单元格内换行；
- 单元格 `min-width: 0`；
- 四向加行/列按钮是表格内部浮层，不占布局；
- 添加/删除操作只替换对应表格范围；
- 固定高度表格在表格内部滚动。

### 代码块

- 行级背景/字体，不靠外层垂直 margin 控制高度；
- 语言高亮按需加载；
- 固定高度代码块在代码区域内部滚动；
- 代码内容不撑宽整个文档面板。

### 分割线

- 作为原子块参与选择；
- 不改变行高；
- 点击/选中不导致布局跳动。
