## 当前架构状态

| 项目 | 状态 |
|---|---|
| 插件注册表 | `src/plugins/registry.ts` 集中组合；feature 插件不互相导入 |
| 插件权限 | 显式 capability policy；非法贡献进入 activation failure |
| 贡献点命名空间 | 强制 `pluginId` 或 `pluginId.*` |
| 渲染器契约 | 内置 renderer props 有 typed contract；自定义 id 保留 string 扩展点 |
| 命令契约 | 插件命令使用 typed `PluginCommandContext`；Tauri 命令统一 `CommandError` |
| 事件 | 应用级事件全部走 `APP_EVENTS`；跨面板拖拽走 typed `PanelEvent` |
| 状态选择 | `select(mapId, node)` 原子更新 |
| 数据迁移 | SQLite schema_migrations、session/theme shared runner、IndexedDB v2 |
| 删除恢复 | 文档软删除、设置页回收站、删除后撤销 |
| 数据维护 | 备份、备份完整性校验、数据库校验 |
| 发布 | 版本单一来源、CI version check、tag release workflow |
