## 已完成的关键能力

### 内核与契约

- 插件 manifest、生命周期、依赖拓扑；
- 命令、事件、输入意图、面板、overlay 贡献点；
- capability 目录、manifest 校验；
- 贡献点结构校验；
- 插件 SDK 导出面快照；
- 前后端 SDK 版本协商；
- 激活故障隔离；
- 插件命令超时。

### 前端

- 菜单、移动导航、错误与状态区域具备 ARIA 语义；
- 按钮/链接统一 focus-visible；

- 功能插件独立目录；
- App 不再直接 import 功能插件；
- 搜索改为 overlay 贡献；
- 移动端壳层、目录、编辑与保存；
- 外观包预览、壁纸、装饰、对比度、SHA-256 完整性。

## 剩余事项

1. 持续维护 GitHub Actions 三平台构建与视觉快照。
2. 功能插件市场/分发仍未实现；`.tnlook` 已具备发布者签名、完整性校验与本地信任。
3. 服务级能力门禁剩余部分（board/theme 的少量直接访问）。
4. capability / data 插件仍为模型层，未做成可分发包。
5. 完整迁移/回滚矩阵与移动端编辑深度回归。
6. 计划文档中的旧清单需与本报告对齐。
