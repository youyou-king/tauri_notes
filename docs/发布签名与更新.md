# 发布签名与更新

当前仓库默认产出未签名安装包。签名、公证和自动更新需要外部凭据，未配置时不会伪造成功。

## 需要配置的 GitHub Secrets

| Secret | 用途 |
|---|---|
| `TAURI_SIGNING_PRIVATE_KEY` | updater 私钥 |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | updater 私钥密码（如有） |
| `APPLE_CERTIFICATE` | macOS 签名证书（base64 p12） |
| `APPLE_CERTIFICATE_PASSWORD` | 证书密码 |
| `APPLE_SIGNING_IDENTITY` | macOS 签名身份 |
| `APPLE_ID` | 公证 Apple ID |
| `APPLE_PASSWORD` | App 专用密码 |
| `APPLE_TEAM_ID` | Apple Team ID |

Windows 代码签名还需要 `WINDOWS_CERTIFICATE` / `WINDOWS_CERTIFICATE_PASSWORD`，并在 release workflow 中接入签名步骤。

## 本地检查

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check-release-secrets.ps1
```

严格模式：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check-release-secrets.ps1 -RequireSigning
```

## Updater

1. 生成 keypair：

```text
npx tauri signer generate -w .tmp/updater.key
```

2. 将 public key 写入 `tauri.conf.json` 的 updater 配置；
3. 把 private key 放入 CI secret；
4. release artifacts 必须由同一私钥签名；
5. 未配置 key 时不启用 updater artifacts，避免产出不可验证的更新包。
