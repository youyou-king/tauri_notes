## 页面布局方案

> 最后核对：2026-10-31 | 当前版本 v0.1.1 | 基线 133 / 38 / 33

> **状态（2026-10-28）**：交互语义参考，部分内容来自 Bevy 阶段。
> 当前实现使用 **dockview** 停靠、React Flow 导图、Tiptap 全块编辑器和
> CSS Token 主题；Bevy Flex 自研部分只保留为交互语义参考。
> 当前架构见 [架构重构方案](架构重构方案.md)。
>
> 目标交互（部分已实现）：
> - 左侧大纲树展示知识库、导图、文档和未归类；
> - 导图、文档、控制台、文档库是 dock 面板；
> - 标签页和面板布局由 dockview 持久化；
> - 自由停靠/分屏使用 **dockview**（标签合并、边缘分屏、分隔条、浮动组）；
> - 节点拖动默认只移动位置；重挂父节点用右键/菜单，避免误搬正文。

### 1. 全局框架

```
┌──────────────────────────────────────────────────────────────┐
│ 工具栏：工程名 · 保存 · 主题切换 · 窗口布局 · 搜索           │
├────────┬─────────────────────────────────────────────────────┤
│        │ ┌─ 标签页栏 ────────────────────────────────────┐   │

│ 导航   │ ├───────────────────────────────────────────────┤   │
│        │ │                                               │   │
│ 导图   │ │                                               │   │
│ ├用户  │ │          当前标签页内容                       │   │
│ │调研  │ │          （导图画布 / 文档编辑器）             │   │
│ ├功能  │ │                                               │   │
```

三区域：工具栏、左侧导航、标签页区域。无底部状态栏。

### 1.1 Pane 与 Tab（对齐 egui_dock）

这里必须区分两层：

```
Dock Tree
└── Split（左右/上下）
    ├── Pane A（Leaf）
    │   ├── Tab 1
    │   └── Tab 2
    └── Pane B（Leaf）
        ├── Tab 3
        └── Tab 4
```

- **Pane**：一个独立矩形区域，有自己的标签栏、活动 Tab、内容区；
- **Tab**：Pane 内的标签，多个 Tab 共用一个内容区，同一时刻只显示 active；
- **多个 Pane**：同时显示多份内容，各有自己的标签栏；
- **新实现**：dockview 管理 Pane/Tab/Split/浮动组；
  Bevy 的 `DockNode` 树只保留为交互语义参考。

拖拽语义：

| 落点 | 行为 |
| --- | --- |
| 另一个 Pane 的标签栏 | Tab 合并/移动，不改变 Pane 大小 |
| Pane 的左/右/上/下边缘 | 按方向新建 Split Pane |
| Pane 中间内容区 | 不处理，回到原 Pane |
| 窗口外 | 后续浮动窗口；当前未接 |
| Pane 之间的分隔线 | 后续改 `ratio`；当前未接 |

“多个标签页同时显示”= 多个 Pane；不是在一个 Pane 里同时铺开所有 Tab 内容。

### 2. 左侧导航

**两个分组**：

- **导图列表**：工程内所有导图。单击打开导图标签页，已打开则切换。右键：重命名、删除、在标签页中打开。
- **最近文档**：最近编辑的节点文档，最多 10 条。单击打开文档标签页。右键：从列表移除、在导图中定位。

**折叠**：`Ctrl+B` 折叠为图标栏，悬停展开。折叠状态持久化到工程偏好。

### 3. 标签页系统

#### 3.1 标签页类型

| 类型       | 图标 | 内容                               |
| ---------- | ---- | ---------------------------------- |
| 导图标签页 | ▦    | 无限画布，树形布局，节点可拖动缩放 |
| 文档标签页 | 📄    | 块级即时渲染的 Markdown 编辑器     |

两种类型平权，没有固定主视图。

#### 3.2 打开方式

- 左侧导图列表单击 → 打开导图标签页。
- 导图标签页内双击节点 → 打开该节点的文档标签页。
- 文档标签页内点击 `#` 标题旁的详情按钮 → 打开子节点文档标签页。
- 左侧最近文档单击 → 打开文档标签页。

已打开的标签页不重复打开，切换即可。文档有未保存修改时，标题后加 `●`。

#### 3.3 预览标签页与固定标签页

- **单击**打开的是**预览标签页**，占用同一位置，下一次单击会替换它。
- **双击**或**拖拽**标签页使其变为**固定标签页**。
- 浏览导图时标签页栏不会膨胀，长期编辑的文档才固定下来。

#### 3.4 标签页操作

| 操作                          | 行为                                   |
| ----------------------------- | -------------------------------------- |
| 单击标签                      | 切换到该标签页                         |
| 中键 / 点击 `×`               | 关闭标签页                             |
| 拖拽标签                      | 停靠、浮动、分屏、合并到其他标签页区域 |
| 右键标签                      | 关闭、关闭其他、关闭右侧、复制路径     |
| `Ctrl+W`                      | 关闭当前标签页                         |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 切换标签页                             |

### 4. 停靠与分屏

> **实现方式**：新主线用 **dockview**。
> Pane 树、标签合并、边缘分屏、分隔条、浮动组由 dockview 负责；
> Bevy Flex 自研实现只保留为语义参考，不再继续开发。

沿用游戏引擎的面板停靠模型：

- **停靠**：拖拽标签页到停靠热区（左/右/上/下/中央），高亮后松手，生成新的面板区域，带独立标签页栏和分隔条。
- **浮动**：拖拽到停靠热区之外，松手后变为浮动面板。可拖动标题栏移动、拖边缘调整大小、双击标题栏最大化、拖回停靠区重新停靠。
- **分屏**：拖拽标签页到标签页区域边缘，出现分屏预览，松手后左右或上下分屏。分屏上限 4 个面板。
- **布局预设**：工具栏“窗口布局”下拉，提供默认、左右分屏、纯文档、纯导图等预设。用户自定义布局可保存为预设，持久化到工程偏好。

典型用法：左侧导图标签页 + 右侧文档标签页，边看结构边写文档；左右两个文档标签页对照写作。

### 5. 导图标签页

标签页内部是一个无限画布：

- 树形自动布局，根节点居中，分支展开。支持左右/上下布局方向切换。
- 滚轮缩放，拖拽空白处平移，双击空白处取消选中。
- 节点可拖动，松开后进入手动布局状态，不再被自动布局移动。
- 右上角浮动控件：缩放比例、自适应视图、布局方向切换。

**节点样式**：

| 状态             | 样式                               |
| ---------------- | ---------------------------------- |
| 空节点           | 虚线边框、降低不透明度、次级文字色 |
| 有内容节点       | 实线边框、正常不透明度、主文字色   |
| 正在编辑         | 左侧色条或外发光                   |
| 手动布局         | 右上角小圆点                       |
| 文档标签页已打开 | 右上角小圆点标记                   |

**节点交互**：

- 单击：选中节点，不打开文档。
- 双击：打开该节点的文档标签页。
- 拖动：**只移动节点位置**，进入手动布局，不改树结构。
- 右键：打开文档、重命名、删除、复制、新建子节点、**重挂到其他父节点**。
  只有“重挂”才迁移标题段落和树结构，且需要确认。

**视口持久化**：标签页关闭时记录视口中心和缩放比例到工程文件（`ui.json`），下次打开恢复。

---

### 6. 文档标签页

- 顶部：面包屑（可点击跳转祖先节点）+ 流式/画布视图切换。
- 主体：块级即时渲染的 Markdown 编辑器。光标所在块显示源码，离开后渲染。
- 画布视图下：块可拖动缩放，右上角浮动模板按钮。
- 滚动位置持久化：标签页关闭后重新打开，恢复到上次阅读/编辑位置。

---

### 7. 导图与文档的联动

- 文档标签页激活时，其所属导图标签页（若已打开）自动选中并聚焦对应节点。
- 若所属导图标签页未打开，不自动打开，避免标签页爆炸。
- 导图标签页中选中节点时，该节点的文档标签页若已打开，标题加粗标记。

---

### 8. 空状态与引导

- **新建工程**：标签页区域为空，显示“从左侧打开导图，或新建导图”。
- **新建导图**：自动打开该导图标签页，画布中央显示根节点“未命名导图”。
- **首次打开文档标签页**：顶部提示“写 `#` 标题生成子节点；详情按钮跳转子文档”。
- **首次拖拽标签页**：停靠热区高亮，显示提示“松手停靠，拖到外侧浮动”。

### 9. 快捷键

| 快捷键                        | 行为                                                |
| ----------------------------- | --------------------------------------------------- |
| `Ctrl+W`                      | 关闭当前标签页                                      |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 切换标签页                                          |
| `Ctrl+B`                      | 折叠/展开左侧导航                                   |
| `Ctrl+Shift+D`                | 当前标签页分屏到右侧                                |
| `F11`                         | 当前标签页最大化/还原（同时隐藏左侧导航和标签页栏） |
| `Ctrl+\`                      | 当前标签页与相邻面板交换位置                        |
| `Ctrl+P`                      | 全局搜索（标题 + 文档全文）                         |

### 10. 设计原则

- **导图与文档平权**：两者都是标签页，没有固定主视图。用户按需打开、并排、停靠。
- **左侧是入口，不是内容区**：左侧只负责“打开什么”，不承载编辑或预览。
- **预览与固定分离**：单击预览、双击固定，避免浏览时标签页膨胀。
- **停靠自由，布局可存**：标签页排列作为工程偏好保存，下次打开恢复。
- **联动但不强制**：文档激活时已打开的导图同步聚焦，但不自动打开新导图标签页。
- **状态持久化**：视口、滚动位置、布局、折叠状态写入工程文件，下次打开恢复。
