# 平台抽象与移动端架构

> 日期：2026-11-04
>
> 状态：Runtime、Shell、端口、平台适配器已落地。
>
> 验证以 `npm test` / `cargo test` / Tauri 构建为准。

## 1. 分层

```text
App
└─ Runtime
   ├─ DesktopShell / MobileShell
   ├─ 端口实现：Dialog / Library / DocumentActions / WorkspacePresenter / Navigation
   └─ 平台适配器：NativePlatform / MobilePlatform
```

`App` 只负责组合 runtime、Store 和业务 effect，不直接判断桌面/移动。

## 2. Runtime 契约

[crate 入口](../src/runtime/contracts.ts) 提供：

- `shellKind` / `layout`
- `services`：Library、Dialog、DocumentActions、WorkspacePresenter、Navigation
- `capabilities`：分享、安全区、虚拟键盘、文件关联等

Shell 通过 Runtime 注入的端口工作，不直接访问 Tauri dialog 或平台路径。

## 3. Shell

- [DesktopShell](../src/ui/shell/DesktopShell.tsx)：桌面 Dockview、工具栏、面板。
- [MobileShell](../src/ui/shell/MobileShell.tsx)：移动返回栈、触摸导航、移动文档页。
- 两者只消费 WorkspaceView 和端口的抽象接口。
- Android/iOS 始终选择移动 Runtime；平板宽度只影响移动布局，不会切换到桌面 Dockview。
- 平台差异（安全区、分享、虚拟键盘）通过 capabilities 表达。

## 4. 身份与位置

- 身份：`LibraryId`，用于会话、Store、Dockview 面板、工作区操作和文档/白板/导图/引用/搜索服务。
- 位置：`LibraryPath`，只用于文件打开、导入、导出、备份、资产、SQLite 和编辑器相对资源。
- 后端 `library_resolver` 负责 `LibraryId → 当前路径`。
- 前端不保存标题副本，标题来自书库 metadata/registry。

## 5. 平台适配器

[platform crate](../src-tauri/crates/platform/src/lib.rs)：

- `home_dir` / `data_dir` / `cache_dir`
- `system_theme`
- `capabilities`
- 文件关联

桌面使用 `NativePlatform`；移动使用 `MobilePlatform`，数据目录由 App 注入。
平台差异不得泄漏到 kernel 或功能插件。

## 6. 移动端

- 移动端与桌面共享 workspace、文档、白板、导图和插件内核；
- 移动 Shell 使用返回栈、触摸手势和紧凑布局；
- 导图模式采用全屏画布 + 悬浮顶栏 + 悬浮视图胶囊，导航通过左侧抽屉召唤；
- 底部视图胶囊持久显示“导图 / 大纲 / 文档”，负责工作区视图切换；知识库生命周期管理在侧边栏；
- 导图、大纲、文档使用单例视图模型，每个视图最多存在一份；
- 导图拖动或整理后保存整张布局的节点坐标；节点位置用 `position_saved` 显式标记是否已定位，`(0,0)` 也是合法坐标；
- 拖动底部视图标签时显示左/右/上/下/中心停靠区，释放后按方向创建或移动分屏；手机竖屏、平板/横屏按拖放方向决定轴，最多两个窗格，上下/左右分别记住 25%–75% 的分割比例；
- 顶栏、按钮、字号和图标使用有上限的流式尺寸，平板不按比例放大；
- 触摸目标不小于 44dp，顶栏/正文/抽屉设置最大宽度；
- 移动抽屉复用桌面顶层导航名称和知识库命令数据，平台专属的导图/大纲/文档仍放在移动视图下；
- 移动顶栏只保留返回/导航和标题，搜索、看板等次级操作进入“视图”子菜单；
- 文档模式使用稳定紧凑顶栏，不叠加画布浮动工具；
- 大纲复用 `ui/outline/OutlineTreeNode`；桌面通过拖放适配器接入 Dockview，移动端不引入面板基础设施；
- 文档操作使用底部 Action Sheet，不把桌面右键菜单塞进画布；
- 托管书库使用 registry 的 App 私有子集，管理入口位于侧边栏“知识库”；
- 打开/导入/导出/分享走 `LibraryPort` 和 `DocumentActionsPort`。

## 8. 非目标

- 不为旧平台适配器保留兼容层；
- 不在 UI 中显示内部路径；
- 不把平台身份写入业务 Store；
- 不为桌面/移动分叉功能插件。
