> 最后核对：2026-10-31 | 当前版本 v0.1.1 | 基线 133 / 38 / 33

> 状态（2026-10-28）：验收清单保留。自动化测试不能替代真实中文输入法；
> 当前自动化环境尚未完成真实 IME 人工验收，发布前仍需在目标输入法环境执行本文步骤。

单编辑器架构只有在真实中文 IME 下通过，才算关闭门禁。合成 `composition` 事件、CDP `imeSetComposition` 都不能替代真实输入法。

## 环境要求

- Windows 已安装微软拼音或其他中文输入法；
- 应用以 `npm run tauri dev` 或正式构建启动；
- 打开的文档至少包含：标题、段落、列表、表格、代码块、任务列表。

检查环境：

```powershell
Get-WinUserLanguageList
```

当前受限会话返回空，说明没有可自动化的中文输入法；必须在有输入法的桌面会话中人工执行。

## 验收步骤

### 1. 基础组合输入

1. 切换到微软拼音；
2. 在普通段落输入 `zhongwen`；
3. 不按空格，观察候选框和组合下划线；
4. 按空格或数字选词，输入“中文”。

通过标准：

- 组合期间不出现重复字母；
- 候选框位置跟随光标；
- 选词后只出现最终汉字；
- 不出现英文原文残留。

### 2. 连续输入与标点

输入：

```text
zhongwen shuru，ceshi。
```

通过标准：

- 中文逗号、句号正确；
- 组合过程中按 Esc 能取消当前组合；
- 不影响下一次输入。

### 3. 编辑键

在组合状态下测试：

- Backspace；
- Enter；
- 左右方向键；
- Shift 选择；
- Ctrl+Z / Ctrl+Shift+Z。

通过标准：

- 不出现半个拼音或重复字符；
- 撤销不破坏 IME 状态；
- 组合中按 Enter 不产生额外换行。

### 4. 跨块选择

1. 输入两段中文；
2. 从第一段拖选到第二段；
3. 输入替换文字。

通过标准：

- 选区连续；
- 替换后块结构正确；
- 撤销恢复原文。

### 5. 表格单元格

1. 进入编辑模式；
2. 点击表格单元格；
3. 用中文输入法输入内容；
4. 失焦保存。

通过标准：

- 组合文字进入单元格；
- 不触发整表重建导致丢字；
- 保存后重载内容一致。

### 6. 任务列表

1. 点击 ☑ 创建任务列表；
2. 在任务文本中输入中文；
3. 勾选/取消勾选。

通过标准：

- IME 输入不误触复选框；
- 勾选状态保存。
