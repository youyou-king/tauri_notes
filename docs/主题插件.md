# 主题插件

主题插件负责外观、主题选择和 `.tnlook` 外观包。

## 代码入口

```text
src/plugins/theme/
├─ index.ts               activate(context) 与贡献注册
├─ manifest.ts            typed manifest
├─ feature.json           manifest / contributions / sdkVersion
├─ ThemeToolbarItem.tsx   顶部主题菜单
├─ AppearanceHost.tsx     壁纸、遮罩和装饰宿主
├─ appearanceRuntime.ts   外观包运行态
├─ appearanceApplier.ts   低层 DOM 适配器
├─ appearancePack.ts      外观包 schema 与校验
├─ appearanceZip.ts       ZIP 解析与资源校验
└─ publisher.ts           ECDSA 签名与信任
```

## 状态所有权

```text
ThemeProvider
  selection / resolved / customThemes
  基础 token、data-theme、data-theme-mode

appearanceRuntime
  applied pack manifest
  dark/light variant assets
  active variant
  data-appearance-pack
  data-appearance-mode

appearanceApplier
  低层 DOM 适配器
  CSS variables / rollback / appearance:applied
```

主题模式变化时由 `ThemeToolbarItem` 监听 `resolved`，调用
`syncAppearanceMode`，不重新加载页面。

## 外观包格式

```text
theme.tnlook = ZIP
├─ appearance.json
└─ assets/
```

支持：

- schema / id / version / modes 校验；
- 资源路径与 ZIP 大小限制；
- SHA-256 完整性；
- 可选 ECDSA P-256 发布者签名；
- publisher trust-on-first-use；
- 对比度警告；
- 导入、预览、应用、回退；
- dark / light variant 运行时切换。

运行时记录保存在 IndexedDB：

```text
tauri-notes-assets / appearance / runtime:v1
```

旧版 localStorage 外观包读取路径保留为一次兼容恢复；新运行时不再写入
旧记录。

## 命令与贡献

```text
theme.open
theme.apply
settings section
toolbar item
```

主题菜单通过共享 `ToolbarMenu` 打开，点击外部或 `Esc` 收起。

设置入口由 shell 提供：

```text
核心工具栏“设置”
快捷键 Ctrl/Cmd + ,
settings.open
```

主题菜单里的“外观设置…”只是另一个入口；主题插件被禁用时，核心设置
入口和插件管理器仍然可用。
